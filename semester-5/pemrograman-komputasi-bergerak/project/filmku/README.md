# FILMKU
A dummy mobile application that I build for my mobile development midterm project. The application is about seeing a film, poster and some information such as sinopsis, rating, and genres (Thank you Letterboxd for the inspiration).

## Tech
- React Native — Mobile application UI development
- Expo — Development and testing environment
- JavaScript (ES6+) — Programming language
- React Hooks (useState) — State management for film details
- Expo Vector Icons (FontAwesome) — Film rating icons
- React Native StyleSheet — UI styling and layout
- Expo Go — Testing the application on Android devices
- Pinterest — Poster image
